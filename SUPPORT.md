# Support

- **Documentation:** [English](https://thiennhant95.github.io/Rampart-PHP/en/) ·
  [日本語](https://thiennhant95.github.io/Rampart-PHP/ja/) ·
  [Tiếng Việt](https://thiennhant95.github.io/Rampart-PHP/vi/)
- **Bugs and false positives:** open an issue with the rule id, file:line, and
  the relevant code snippet (redact secrets).
- **Feature requests:** open an issue describing the target framework and the
  exact behavior you expect.
- **Security reports:** use GitHub private vulnerability reporting, see
  [SECURITY.md](SECURITY.md).
- **Questions:** start a GitHub Discussion or open an issue labelled
  `question`.
- **Related projects:** [Rampart (Laravel)](https://github.com/thiennhant95/Rampart) ·
  [Rampart WP](https://github.com/thiennhant95/Rampart-Wordpress)

We do not provide commercial support. The project is MIT licensed and maintained
on a best-effort basis.
